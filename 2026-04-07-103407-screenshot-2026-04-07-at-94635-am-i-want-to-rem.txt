  Root cause: When you ask "tell me section 3", RAG retrieves just the section
  title chunk because that's the highest-similarity chunk. The LLM can expand it
   when running, but when down — only the bare title shows. Also, my previous
  first_para fix made it worse since the first paragraph IS just the title.

  Solution: Build a FAQ / Curated Answer system:
  - Admin saves Q&A pairs to the database via API
  - At query time, the bot checks FAQs first using semantic similarity on the
  question
  - If a FAQ matches (≥75% similarity), the curated answer is returned directly
  — no guessing, no LLM needed
  - Falls through to normal RAG/LLM if no FAQ matches
